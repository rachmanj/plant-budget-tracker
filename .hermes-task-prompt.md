## Requirements

### 1. ThemeProvider (new file, `.tsx`)
Create a React context provider, e.g. `resources/js/providers/ThemeProvider.tsx` + hook `resources/js/Hooks/useTheme.ts` (check existing folder conventions first — there are `Hooks/` and `hooks/` dirs; match where `useArkfleet.ts` lives).

Behavior:
- **Default = DARK** (per Iwan's requirement)
- Persist in `localStorage` key `pmb-theme` (`'dark'` | `'light'`)
- On mount, read stored value; if none, check `window.matchMedia('(prefers-color-scheme: dark)')` then fall back to dark
- Set `document.documentElement.setAttribute('data-theme', isDark ? 'dark' : 'light')` on change (useEffect)
- Also set `document.body.style.background` to the AntD token `colorBgLayout` value for the current mode so the page chrome (outside AntD components) matches: dark `#000000`-ish AntD layout bg (`#141414`? use antd's own dark colorBgLayout), light default. Better: import `theme` from antd and read via `theme.darkAlgorithm`/`defaultAlgorithm` — simplest robust approach: set CSS in `resources/css/app.css` with `html[data-theme='dark'] body { background: #141414; }` and light equivalent `#f5f5f5` (or antd colorBgLayout `#f0f2f5`? use `#f5f5f5` to match Login). Do it in CSS, not JS.
- Export `useTheme()` → `{ isDark, toggleTheme }`

### 2. Wire into app.tsx
`resources/js/app.tsx` currently has a plain `ConfigProvider` with `colorPrimary: '#1677ff'`, `borderRadius: 6`, locale `id_ID`.

Change to (keep `id_ID` locale — this is an Indonesian app, do NOT switch to en_US):
```tsx
import { ConfigProvider, App as AntApp, theme } from 'antd';
import idID from 'antd/locale/id_ID';
import { ThemeProvider, useTheme } from './providers/ThemeProvider';  // path per actual file

const { darkAlgorithm, defaultAlgorithm } = theme;

function ThemedApp({ children }) {
  const { isDark } = useTheme();
  return (
    <ConfigProvider
      locale={idID}
      theme={{
        algorithm: isDark ? darkAlgorithm : defaultAlgorithm,
        token: {
          colorPrimary: isDark ? '#2dd4bf' : '#0d9488',   // teal/emerald finance-professional palette
          colorSuccess: '#10b981',
          colorWarning: '#f59e0b',
          colorError: '#ef4444',
          colorInfo: '#0ea5e9',
          borderRadius: 8,
        },
      }}
    >
      <AntApp>{children}</AntApp>
    </ConfigProvider>
  );
}

// setup(): wrap <App {...props}/> with <ThemeProvider><ThemedApp>...</ThemedApp></ThemeProvider>
```
Update the Inertia `progress` color from `#1677ff` to `#0d9488`.
No default AntD blue (`#1677ff`) may remain anywhere.
